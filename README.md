# Reanty - Real Estate Landing Page

Landing page bất động sản dựng lại từ thiết kế Figma 
https://www.figma.com/design/0TUU6ASQ70K1MkGcamHUuS/FASTCODING?node-id=0-1&p=f&t=q7j0D2lZgOQZu9UZ-0, bằng HTML và CSS thuần, không dùng framework hay JavaScript.

## Demo

https://thanhph8600.github.io/test-fastcoding

## Công nghệ

- HTML5
- CSS3 (custom properties, flexbox, grid, `:has()`)
- Không dùng JS, không dùng framework

## Cấu trúc thư mục

```
.
├── index.html
├── css/
│   └── style.css
└── assets/
    └── images/
        ├── icons/        # icon SVG xuất từ Figma
        └── unit-thumb.jpg
```

## Chạy thử trên máy

Chỉ cần tải source về rồi mở trực tiếp file `index.html` bằng trình duyệt (double-click là chạy), không cần cài đặt hay chạy server gì thêm.
